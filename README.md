# jiuhu-dsh · 酒狐的 DSH 部署改动

> **这是 SurfCore 的个人部署改动，不是新框架，也不是开箱即用的产品。**
> 上游（[Mieksido/surfcore](https://github.com/Mieksido/surfcore)，MIT）负责把模型接进 QQ / B 站；
> 我在这上面只做一件事：让她**更像个人、记得住、管得住**。
>
> 全部改动都能用 `node scripts/verify.mjs` 复核「语法 / 预设 / 路由 / 工具 / 提示词结构」有没有退化。

**支持范围**：Linux 优先（阿里云 Ubuntu 实测）；Windows 与 SnowLuma 桌面版未验证。
**仓库性质**：个人部署记录，配置与素材均未包含。

## 一眼看懂：解决的 6 个问题

| 问题 | 上游默认的表现 | 我们的做法 |
| --- | --- | --- |
| 群里也在撒娇、乱背设定 | 群聊和私聊注入同一份人格卡 | **人格四层**：群里只装「身份 + 语气 + 场景」，私聊才装全量 |
| 她把我私聊的事讲给群 | 记忆卡全局一份，注入不分会话 | **记忆按会话隔离**：群拿不到你的私聊记忆，多个人私聊也不串台 |
| 「只听主人」设了也没用 | 模式只拦「新消息」，补唤醒/定时器绕过去 | **唤醒闸门收口**：所有唤醒走一个入口，静音/学习/额度统一裁决 |
| 不知道钱花在哪、卡在哪 | 只有 token 总量 | **面板 15 页**：花费 / 健康 / 记忆 / 白名单 / 印象 / 操作 |
| 改一个功能要动 1.7 万行的大文件 | 100+ 处内联补丁 | **四个固定插口**：新功能只注册，不改装配代码 |
| 升级上游靠手工合并 | 无基线、无脚本 | **快照基线 + 三方升级脚本**：改坏了 5 秒发现 |

## 功能清单

### 1. 人格与说话方式

- **核心 / 语气分层**：`persona.md`（身份、外形、认人、边界）+ `persona.tone.md`（口癖、句长、标点、**8 组对照示例**）+ `persona.daily.md` + `persona.scenes/`。
- **群聊只装语气层**：群聊注入「身份底座 + 语气 + 场景」，私聊才装全量。
- **语气层靠示例**：只写规则不管用，模型会退回书面腔——所以写「别这样 → 要这样」。
- **称呼可选**：不强制每句都喊主人，想喊才喊；标点不追求工整。
- **不许交代工具**：不说「我查一下」「根据资料」，直接说结论。

### 2. 记忆

- **按会话检索**：每轮按 `conversationKey` 取相关旧事注入（约 700 字）。
- **名额分配**：人格底座 3 条 + 本会话 9 条 + 公开(B站) 2 条——公开记忆挤不掉本会话。
- **无归属条目**：没有会话标记的老记忆默认只在主人私聊出现。
- **记忆星图**：`star-map/memory-map.html`，单文件零依赖；大小=权重、亮度=多久没想起、离中心=重要度+年龄；单击看详情、滚轮缩放、支持筛选搜索。
- **印象库**：从记忆里提炼「她对他的看法」（≤50 条，注入前 8 条），**只注入主人私聊**。
- **欠事 / 自我笔记 / 心情**：都作为提示词块参与装配。

### 3. 闸门：静音 / 学习 / 额度

| 层 | 作用 | 在哪 |
| --- | --- | --- |
| 白名单 | 只有名单里的群 / 人能触发 | 面板「白名单」页 |
| 静音 | 单个会话「暂时不理」，不删白名单，号码仍保存 | 面板「静音与学习」页 |
| 学习模式 | 某个群「只看不聊」：不唤醒、不发言 | 同上 |
| 每日额度 | 群 60 / 私聊 40 次唤醒，超了当天不再打扰 | 自动 |
| 敏感内容 | 命中敏感词条不写入记忆、不进提示词 | 自动 |

**闸门位置只有一个**：`sendWakePromptV2()` 入口。手动/强制唤醒（`manual/admin/force`）例外放行——否则静音期间连主人都喊不动她。

### 4. 面板（15 页，零依赖）

`总览 · 健康检查 · 花费 · 记忆 · 白名单 · 静音与学习 · 印象库 · 记忆体检 · 功能开关 · 会话与额度 · B 站 · 语音与表情 · 人格四层 · 操作 · 补丁清单`

- 服务：`panel/server.mjs`（单文件、零依赖），只监听 `127.0.0.1:3200`
- 令牌由服务端注入，**浏览器里看不到任何凭据**
- 白名单改动会自动重启桥接（约 5 秒生效）
- 记忆星图直接内嵌，ETag 缓存（记忆没变返回 304）

### 5. 工程结构

- **四个固定插口**（`src/hooks.js`，87 行）：`incoming` / `beforeGenerate` / `afterGenerate` / `afterSend`，另有 `wakeGate`。
- **已注册 10 个提示词块**：人格、管理员、B站简报、记忆卡、会话记忆、印象、欠事、自记、心情、恢复提示。
- **保命层留在主干**：限流、去重、日志脱敏、错误只报主人——不进插口，避免漏注册。
- **验收基线**：`scripts/verify.mjs`（401 文件语法 → 预设 → 路由 → 工具清单 → 提示词结构快照）。
- **升级脚本**：`scripts/upgrade.mjs`（经 `gh-proxy` 拉上游 tag → 三方对比 → 列冲突 + 待复查标记）。
- **自愈**：systemd `Restart=always` + 看门狗每 2 分钟四路探活（桥接 / DSH / SnowLuma / 面板）。

```

    │
    ▼
SnowLuma (OneBot v11) ──8000/3000──▶ 桥接 bridge.js
                                      │

                                      ├─ wakeGate：静音 / 学习 / 额度
                                      ├─ beforeGenerate：10 个提示词块（走插口）

                                      └─ afterSend：回执（预留）
                                              │
面板 panel/server.mjs ─── 读桥接接口 + 读写 state ───┘
    (127.0.0.1:3200)
```

## 快速开始

```bash
# 1. 取上游
git clone https://github.com/Mieksido/surfcore.git && cd surfcore
git checkout v0.8.4

# 2. 打补丁（先 check）
git apply --check /path/to/surfcore-0.8.4-local.patch
git apply /path/to/surfcore-0.8.4-local.patch

# 3. 放人格卡
cp -r persona/* characters/<你的角色>/

# 4. 配 config.json（ownerQQ / 白名单 / consoleToken）

# 5. 验收
node scripts/verify.mjs
```

## 隐私边界

**进仓库的**：人格四层（脱敏）、记忆星图页面、补丁、文档。

**不进仓库的**：

- `config.json`（含 consoleToken、QQ 号）
- 聊天记录与记忆卡原始数据
- 语音库、立绘、表情素材（版权）
- 服务器地址与任何凭据

所有 QQ 号在人格卡里替换为 `<主人QQ>` / `<QQ号>` / `<群号>` 占位符。

## 常见问题

**Q：能直接拿来跑吗？**
不能。这是个人部署的改动记录，配置、素材、人格设定都需要你自己准备。

**Q：为什么补丁这么大（203KB）？**
它包含记忆检索、插口改造、闸门、面板接口等十几块改动，直接对上游 0.8.4 生成。

**Q：升级上游会不会很难？**
有 `upgrade.mjs` 做三方对比，冲突文件会列出来；服务器连不上 GitHub 时走 `gh-proxy`。

**Q：群里会不会看到她「对主人的看法」？**
不会。印象库只注入主人私聊，群和其他人私聊都拿不到（有测试验证）。
